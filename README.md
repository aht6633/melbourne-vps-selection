## 512MB 内存能干什么

这台机器的配置单看着别扭：2 核 CPU 只配 512MB 内存。

CPU 给得宽，是因为这类业务几乎不吃 CPU，瓶颈全在 IP 和网络上。内存卡在 512MB，则直接决定了它能做什么、不能做什么。装个精简版 Debian 或 Ubuntu，再挂一两个轻量服务，内存还剩得下。装 Windows 不够，装带数据库的建站面板也够呛，WordPress 加 MySQL 在 512MB 上基本会不停 OOM。

所以别想着"顺手建个站"。它卖的是一个干净的澳洲出口 IP，算力只保证你能连上去操作账号。

10GB SSD 同理，装完系统和常用工具就没多少余量了。2TB 双向流量按发布视频的用量算，正常运营一个月用不完；200Mbps 带宽在澳洲节点里算宽的，同门的悉尼款只有 100Mbps。

## 上手时的几个细节

社区里流传的操作建议，和官方政策无关，但对降低封号率有实际帮助：

VPS 系统时区改成澳洲时区（AEST 或 AEDT），浏览器时区也调成一致。IP 在墨尔本、时区是东八区，这种组合很容易被识别。

一个 IP 先挂 1 到 2 个号，观察一段时间播放量正常再加。一上来铺一堆号是封号高发区。

登录环境保持稳定，别今天用这台、明天换一台登同一个号。

用远程桌面或安卓模拟器操作，不要用脚本批量跑。
